# 가이드라인 LLM 셀렉 (PeterJ 지시 2026-08-17)

> *"셀렉은 LLM 통해서 나한테 맞는거 리스트를 정하고."*

## 1. 규칙 점수로는 못 가르는 것

기존 `GuidelineScorer` 는 **기관 권위 · 주제어 매칭 · 최신성 · 발견경로 신뢰도**를 잰다.
= "이것이 권위 있는 최신 지침인가".

2년치를 미리 풀링하면 그것만으로 못 가르는 것이 수백 건 섞인다:
- 소아 전용인가 (PeterJ 는 성인 응급·중환자)
- 한 나라 보험·제도 얘기인가
- 응급실·중환자실에서 **손에 잡히는** 내용인가
- 지침이 아니라 지침을 **연구한** 논문인가 (분류기가 일부 거르지만 제목만으로는 한계)

그 판단만 LLM 이 한다. **순위를 뒤집는 것이지 수집을 대신하는 것이 아니다.**

## 2. 구조

```
풀(2년) ─ 분류 ─ 규칙점수 ─ [LLM 셀렉] ─ guidelineRank ─┬ 발행 픽 (하루 1편)
                                                        └ 예고 리스트 (7일)
```

| 파일 | 역할 |
|---|---|
| `src/utils/guidelineFit.js` | 순수 함수 — 배치 · 프롬프트 · 판정 적용. 네트워크 없음 |
| `src/agents/GuidelineFitAgent.js` | LLM 호출 (배치 20건). 실패는 전부 소프트 |
| `src/utils/guidelineRank.js` | **정렬 정본.** 발행 픽과 예고 리스트가 같이 쓴다 |
| `scripts/guideline-fit.mjs` + `guideline-fit.yml` | 벌크 판정 (2년 풀 첫 통과용) |

`rank = keep:false ? -1000+priority : (적합도 × 10) + priority`
→ 적합도가 규칙 점수(0~12)를 지배한다. 무판정은 규칙 점수만으로 선다(0점 취급 아님).

## 3. 되돌릴 수 있는 쪽으로 튼 결정 셋

1. **안 맞는다고 `rejected` 로 안 내린다.** `mergeCandidates` 는 rejected 를 영구 배제로
   다루므로 LLM 이 한 번 잘못 자르면 그 지침은 다시는 안 들어온다. `needsReview` 로
   **격리**한다 — 화면의 ▶ 로 되살릴 수 있고 판정 버전이 오르면 자동 복구된다.
2. **빠뜨린 판정은 0점이 아니라 무판정.** LLM 이 한 건 빠뜨린 날 그 지침이 조용히
   격리되면 안 된다.
3. **프롬프트가 "애매하면 keep:true"** 라고 지시한다. 버려진 것은 사람이 다시 못 보지만
   남은 것은 화면에서 한 번에 지울 수 있다.

## 4. ★ 붙이자마자 잡힌 설계 결함 하나

계약 테스트가 적색이 됐다 — **PeterJ 가 수동 승인한 문서를 LLM 이 "실무와 무관" 으로
보고 격리해서 그날 발행이 통째로 사라졌다.** 확정 ⑤-A(수동 승인은 자동 필터를 우회한다)
정면 위반이다. `unscoredItems` 가 `manualApproved` 를 제외하게 고쳤다.
사람이 이미 고른 것을 기계가 다시 심사하면 안 된다.

## 5. 비용 관리
- 데일리는 **하루 40건**까지만 판정한다(`GUIDELINE_FIT_DAILY_LIMIT`).
- 예산이 모자라면 **규칙 점수 높은 것부터** — 먼저 나갈 후보에 판정이 먼저 붙어야 한다.
- 이미 판정받은 것은 다시 안 부른다(`llmFit.version` 으로 본다).
- 2년 풀 첫 통과는 `guideline-fit.yml` 로 한 번에(기본 400건).
- 끄는 스위치: `ENABLE_GUIDELINE_LLM_FIT=false` → 규칙 점수로 종전대로 돈다.

- `npm run test:unit` 704 → **721** 전부 초록 · spec-lint 통과.
- 변이 5건(데일리 배선 · 발행 픽 정렬 · 예고 정렬 · manualApproved 예외 · rejected 강등)
  전부 적색 확인.

  판정되게 고쳤다.
- ★ 테스트가 **실제 LLM 을 때리고 있었다**(계약 테스트 18초). 판정 결과에 따라 초록·적색이
  갈리는 비결정 테스트다. `ENABLE_GUIDELINE_LLM_FIT=false` 로 막고, 셀렉 자체는
  주입한 스텁으로 본다.
