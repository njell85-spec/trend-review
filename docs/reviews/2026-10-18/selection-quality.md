2. **발행 후 리필 상태 보존**: publisher 뒤에 채운 큐를 최종 daily state commit 목록에
   포함했다. 운영에 적용되기 전에는 실제 다음 실행 지속성을 검증할 수 없다.

   `ROSC→hysteroscopic` 같은 부분문자열 오매칭을 제거했다. 긴 설정 어근은 그대로다.
   기존 가중치·임계값·기관 승인·수동 승격·LLM 프롬프트는 변경하지 않았다.
   후속 검수에서 확인한 DNACPR 손실은 **CPR의 명시적 별칭 `dnacpr` 하나**로 복구했다.

   키워드 및 지침 점수에서 CPR과 동등한 매칭을 회귀로 확인했다.
4. **종합 카드 빈 PubMed 링크**: 생성기와 기존 HTML 1곳을 `출처: 위 문헌별 링크`로

   큐/주기 시험의 기본 수집기를 stub으로 바꿨다. 분석 테스트는 각자 필요한 stub을 덮어쓴다.

현재 코드와 과거 커밋의 바이트 차이는 별도로 확인해야 하므로, 모든 과거 실행의 호출 인자까지
재현했다고 주장하지 않는다.

## 검증·잔여

추가 전달 항목의 현재 대조(전언을 결론으로 사용하지 않음):

- **9/18 결번**: 논문·가이드라인·리뷰 장부와 HTML 모두 그날 항목이 없다.
  [9/18 KST Daily 실행](https://github.com/njell85-spec/trend-review/actions/runs/35287551157)은
  UTC 9/17 23:35:54 시작, 코드 `cda9295eb0fe40bfc41d481db2dfa22218ed263b`, success다.
  보존 로그 23:37:19–20에는 월별 검색의 `Found undefined total, retrieved 0 PMIDs`,
  legacy 폴백의 `No PMIDs found for query`, 이어서 orchestrator의
  `No papers collected — aborting pipeline`가 있다. **수집 0건 후 조기 return으로
  지침/리뷰 단계까지 진행하지 않은 것이 직접 결번 원인**이다. 성공 표시는 발행 성공이 아니다.
  검색 응답의 원시 본문/상태가 없어 실제 검색 0건인지 서비스 오류 응답인지 근본 원인은
  확정하지 못했다. 9/19·9/20 발행은 있으며 외부 재실행은 하지 않았다.
- **2026 ESC 심부전 중복 위험**: [PubMed 42661420](https://pubmed.ncbi.nlm.nih.gov/42661420/)에서
  제목과 DOI `10.1093/eurheartj/ehag100`을 확인했다. 기존 URL 카드는 8/29 발행되어 있고
  해당 PMID는 현재 needsReview, llmFit 9/keep:true이며 HTML에는 없다. 따라서 **현재 중복
  발행은 아님**. 승인 전에 URL/DOI/PMID를 같은 자료로 연결해야 한다. 종합 카드와 개별
  지침은 목적이 다르므로 단순 중복 삭제 대상으로 보지 않는다.
- **종합 꼬리 링크**: 최신 HTML에 실제 빈 PubMed 링크 1개가 있었고 이번에 수정했다.
- **페이월 보강**: 경로가 전혀 없다는 과거 설명은 현재 코드/coverage와 맞지 않는다.
  web-augmented 13건이 있으나 abstract-only도 34건이다. 전문 확보를 보장하는 경로로
  표현하면 안 되며 본문/보강 출처 구분을 유지한다.

실행 명령·결과는 [validation.md](validation.md), 현재 작업 상태와 다음 행동은
[공통 현재 인계](../../../HANDOFF.md)에 둔다. 로컬 변경만 수행했으며 배포하지 않았다.
모바일 실물 렌더는 Chromium의 Windows sandbox 파일 접근 오류로 완료하지 못했다.
우회 플래그나 권한 완화는 적용하지 않았다. 화면 폭·터치 동작·외부 링크 응답은 미검증이며,
HTML 카드/표/식별자/빈 링크의 정적 검사는 실측했다.
