## 이번 수정과 비교

1. **이미 소진된 후보를 잘라낸 뒤 순위 제한**: 종전에는 월 top-K와 상위 14개를 뽑은 다음
   이미 발행/거절한 것을 빼므로, 새 후보가 있어도 큐가 빈다. 월 풀 구성과 큐 저장 전에
   소진 집합을 제외한다. 0건 리필은 성공으로 보고하지 않는다. 동일 30개 입력에서 상위
   14개가 소진된 회귀 사례는 종전 큐 0건 → 수정 14건. 이는 버그 재현이며 역사적 성과값은 아니다.
2. **발행 후 리필 상태 보존**: publisher 뒤에 채운 큐를 최종 daily state commit 목록에
   포함했다. 운영에 적용되기 전에는 실제 다음 실행 지속성을 검증할 수 없다.
3. **짧은 약어 단어 경계**: `STEMI→systemic`, `ARDS→standards/towards`,
   `ROSC→hysteroscopic` 같은 부분문자열 오매칭을 제거했다. 긴 설정 어근은 그대로다.
   기존 가중치·임계값·기관 승인·수동 승격·LLM 프롬프트는 변경하지 않았다.
4. **종합 카드 빈 PubMed 링크**: 생성기와 기존 HTML 1곳을 `출처: 위 문헌별 링크`로
   바꿨다. 실제 문헌별 링크를 유지하며 새 URL을 만들어내지 않았다.
5. **시험 환경**: Windows CRLF에서도 workflow 검사가 작동하도록 정규화하고, 리뷰
   큐/주기 시험의 기본 수집기를 stub으로 바꿨다. 분석 테스트는 각자 필요한 stub을 덮어쓴다.
6. **음성 fit과 queued 상태 불일치**: 최신 큐의 `42663032`는 제목상 AI가 예측한 ESC 지침이며,
   기존 llmFit도 2점/keep:false로 판정했지만 status는 queued였다. 종전 선택기는 낮은 순위로
   미룰 뿐 발행을 금지하지 않았다. 발행과 예고가 공유하는 필터에 keep:false 제외를 추가했다.
   명시적 수동 승인/승격은 계속 우선하며 기존 장부의 상태는 일괄 수정하지 않았다.
   최신 보존 큐에서 이런 불일치는 **31건**이며, 보호 조건 적용 시 자동 발행 가능분은
   queued 203건에서 **172건**으로 줄어든다. 후보 자체를 삭제하지 않아 검토·승격은 가능하다.

8/16 census 8개 축에서 PMID 중복을 제거한 **동일 5,282개 공개 메타데이터**에 양쪽
스코어러를 적용했다. `PMID % 5 == 0`을 holdout으로 고정했으며 가중치 학습은 없다.

지침 최신성 시계는 2026-10-18로 고정했다. **분류기·수동승격·LLM·쿨다운까지 포함한
과거 운영 재현이 아니라, 보존 후보의 규칙 점수 민감도 비교**다. 실제 논문 후보풀은 아니다.
장점은 명백한 어휘 오매칭 제거이고, 단점은 미등록 결합 약어(예: DNACPR 안의 CPR)의
점수도 내려갈 수 있다는 점이다. NSTEMI/ECPR는 별도 설정 단어가 있으며 긴 임상 표현은
여전히 맞는다. 영향 목록을 남겼으므로 다음 검토자는 제거된 신호와 임상 적합성을 구분해 본다.
수치만으로 precision/recall 개선이나 임상 안전성을 주장하지 않는다.
