# 독립 검수 P2 후속 — 캐시 생성 근거 보존

대상: 코드 `f35563c`, 인계 `bc3837b`. 기존 선정 품질 검토의 후속 보완이다.
PR #165의 원격 `5dc5d16`과 기존 장부·발행물은 보존한다.

## 검수와 저자 재현을 구분

독립 검수자는 신규 9/9 통과를 확인했지만, 빈 메모리 캐시에서 별도 P2를 재현했다.
본문 없는 입력에 모의 모델이 `full-text`·긴 내용·허용 도메인 링크를 반환하면 카드만
`abstract-only`로 낮추고 원래 모델 값이 캐시에 저장됐다. 같은 PMID에 PMC 본문 525자를
공급했을 때 추가 모델 호출 0회로 이전 내용이 재사용되며 `full-text`로 승격됐다.
근거 기록도 새 PMC 본문을 분석에 사용한 것처럼 연결됐다. 실제 운영 발생은 미확인이다.

저자는 이 검수 결과를 읽고 현재 로컬 코드에서 새 회귀시험을 실행했다. 수정 전 15개 중
10통과/5실패로 캐시 재사용·지문 누락·구형 값 호환·생성 근거/열람 표시·동일 DOI 경계를
확인했다. 이 결과는 저자의 재현이며 독립 검수의 재실행 결과로 표현하지 않는다.
고친 코드에 대한 추가 독립 검수는 아직 받지 않았다.

## 수정

- 모든 분석 모드(review/guideline/reference/synthesis)에 `v6` 캐시 네임스페이스와
  근거 정책 버전 `ep1`을 적용했다. 정확한 기본 프롬프트 및 공급 본문·출처를 지문화한다.
  PMC/OA/사용자 본문, 보강 텍스트·출처, 종합 문헌 각각의 본문·출처 변화도 구분한다.
- 캐시에 결과와 함께 생성 시각·입력/결과 지문·공급 본문 문자 수/출처·정책 버전을 저장한다.
  리뷰의 모델 coverage 주장과 허용 출처 수, 적용 coverage도 생성 당시 근거에 포함한다.
  읽을 때 현재 입력/정책/결과와 대조하고 일치할 때만 채택한다. 카드에는 저장된 생성 근거를
  전달하며 새 입력을 옛 결과의 생성 근거로 다시 붙이지 않는다.
- 근거 없는 구형 값은 재사용하지 않는다. 기존 v5 키를 조회하거나 운영 캐시를 일괄 삭제하지
  않는다. 새 키 안에 잘못 들어간 raw 값이나 지문/정책이 다른 레코드도 miss로 처리한다.
  이는 캐시 호환 정책 변경이다. 실제 적용 시 최초 실행의 캐시 적중률이 낮아질 수 있다.
  허용된 환경에서만 새 분석이 수행되며 이번 시험은 모의 모델만 사용했다.
- 동일 계보에서 정규화한 DOI가 같은데 제목 연도만 다르면 `same-doi-not-new-edition`으로
  보류한다. DOI 문자열 하나를 공동출판 관계의 확정 증거로 승격하지 않으며, 두 문서를 자동
  삭제·병합하지 않는다. 서로 다른 DOI를 가진 공동출판 전체를 해결한 것은 아니다.

허용 도메인 URL은 실제 열람·논문 동일성·전문 확보를 증명하지 않는다.
`webRetrievalVerified:false`를 명시했다. 기존 `web-augmented`는 모델 보고와 도메인 정책에
기반한 분류이며 검증된 도구 열람 영수증이 아니다. 전문 문자 수 역시 입력 존재 기준이다.
도구 호출 이력과 본문 동일성을 검증하는 새 수집 체계는 이번 범위 밖이다.

## 검증과 남은 한계

신규 [analysisEvidenceCache.test.mjs](../../../test/analysisEvidenceCache.test.mjs)는 빈 캐시에서
생성→새 PMC 본문→동일 입력 재사용을 실제 `analyze()` 경로로 실행한다. 입력 변경 시 새 모델
호출과 새 내용, 동일 입력일 때 캐시 적중 및 생성 근거 보존을 확인한다. 구형/정책 불일치
캐시, 모든 모드의 본문·출처 변화, 종합 문헌 본문 변화도 확인한다.
같은 DOI/다른 제목 연도 합성 회귀 1개를 추가했다.
[합성 재현 값](cache-review-evidence.json)과 [전체 검증 요약](validation.md)을 함께 남긴다.

기존 모바일 실물·과거 카드 정정·PADIS 트랙 조정·본문 완전성/실제 열람 검증은 남아 있다.
이 수정은 전체 선정 품질이나 임상 정확도의 향상을 검증한 것이 아니다.
